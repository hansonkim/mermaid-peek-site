Example code review flow

flowchart LR
    A[Change proposed] --> B{Review}
    B -->|Approve| C[Merge]
    B -->|Request changes| D[Update code]
    D --> E[Run tests]
    E --> F[Update diagrams]
    F --> B
    C --> G[Deploy staging]
    G --> H[Verify]
    H --> I[Release]

Use Fit to see the whole flow, then zoom in and drag to inspect details. Save the PNG if you need an image.
